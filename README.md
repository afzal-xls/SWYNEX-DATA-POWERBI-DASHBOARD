# SWYNEX-DATA-POWERBI-DASHBOARD
Interactive cafe sales Dashboard using Microsoft  Power BI | SWYNEX TASK 3
☕ SWYNEX Cafe Sales Analysis – Power BI Dashboard

📌 Project Overview

This project focuses on analyzing cafe sales data using Microsoft Power BI. The goal is to understand sales performance, identify trends, and present useful business insights through an interactive dashboard.

🎯 Project Objectives

- Analyze overall cafe sales performance.
- Track important business KPIs.
- Identify sales trends and patterns.
- Understand customer purchasing behavior.
- Create an interactive dashboard for better decision-making.

🛠️ Tools & Technologies

- Microsoft Excel – Data Cleaning and Preparation
- SQL – Data Analysis
- Microsoft Power BI – Dashboard Development
- GitHub – Project Documentation and Portfolio

📊 Dashboard Features

- Key Performance Indicators (KPIs)
- Sales analysis charts and visualizations
- Interactive slicers and filters
- Sales trends and comparisons
- Business insights from cafe sales data

🧹 Data Cleaning

- Worked with the cafe sales dataset containing 10,000 original rows.
- Handled missing values.
- Standardized text and date formats.
- Removed unrecoverable records.
- Prepared 9,972 clean rows for analysis.

📈 Key Insights

The dashboard helps explore:

- Overall sales performance.
- Popular cafe items.
- Payment method distribution.
- Sales by location.
- Monthly sales trends.
